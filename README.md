# Auto Defense

브라우저에서 실행하는 2D 탑뷰 실시간 오토 디펜스 게임입니다.

## 실행 방법
GitHub Pages를 켜면 브라우저에서 플레이할 수 있습니다. 저장소 설정의 **Pages**에서 배포 브랜치를 `main`, 폴더를 `/ (root)`로 선택하세요.

또는 저장소를 내려받아 `index.html`을 브라우저에서 열면 됩니다.

## 현재 기능
- 위에서 내려다보는 2D 전장
- 실시간 자동 이동 및 전투
- 유닛 소환 (10G)
- 같은 유닛 3개 합성
- 무한 웨이브 및 보스 출현
- 기지 체력과 골드 보상
- 일시정지 및 1배속 / 2배속

## 조작
- 유닛 소환: **유닛 소환** 버튼
- 합성: **3개 합성** 버튼
- 배속: **1× / 2× 속도** 버튼
- 전투 중단: **일시정지** 버튼

현재 버전은 초기 프로토타입이며, 전투 밸런스와 추가 유닛/스킬은 개발 중입니다.
