# Turn-Based Auto Battler

브라우저에서 실행하는 2D 탑뷰 턴제 오토배틀러 프로토타입입니다.

## 실행
저장소의 `index.html`을 브라우저에서 열거나 GitHub Pages를 활성화하세요.
GitHub Pages 설정: **Settings → Pages → Deploy from a branch → main → /(root)**

## 한 턴의 진행
1. **준비 단계:** 인컴 골드를 받고 상점에서 유닛을 구매합니다.
2. **구매 및 합성:** 상점은 3칸이며 구매 비용은 15G입니다. 같은 캐릭터·같은 등급 2개를 드래그해 합성하면 다음 등급으로 진화합니다.
3. **배치:** 보유 유닛을 전장 아래쪽 아군 구역으로 드래그합니다. 최대 5명까지 배치할 수 있습니다.
4. **전투:** 전투 시작 버튼을 누르면 양 진영이 실시간 자동 전투를 합니다. 한 진영의 전투 가능한 유닛이 모두 쓰러지면 전투가 종료됩니다.
5. **다음 라운드:** 적 처치 노획 골드와 인컴을 반영하고 상점을 새로 구성합니다.

## 경제 및 등급
- 시작 골드 30G, 시작 인컴 2
- 노획: 적 처치마다 +1G
- 인컴: 다음 라운드 준비 단계에서 현재 인컴만큼 지급
- 인컴 성장: 라운드마다 +2
- 상점 등급 확률: 일반 70%, 희귀 25%, 레어 5%
- 등급 순서: 일반 → 희귀 → 레어 → 영웅 → 전설
- 구매 비용: 15G

## 조작
- 상점 카드 클릭: 구매
- 보유 유닛 카드를 전장으로 드래그: 배치
- 같은 캐릭터·같은 등급의 보유 카드 위로 드래그: 합성
- 전투 시작: 실시간 자동 전투 시작
- 다음 라운드: 인컴 지급 및 상점 갱신

현재 버전은 핵심 턴제 루프를 구현한 초기 프로토타입입니다. 캐릭터별 고유 특성, 인컴 변동 특성, 밸런스, 저장 기능 등은 추후 확장 대상입니다.
